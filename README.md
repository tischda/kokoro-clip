# kokoro-clip

Reads Read Windows clipboard text aloud with automatic language detection.

## Install

Install Kokoro-FastAPI TTS engine.

```
go install github.com/tischda/kokoro-clip@latest
```

## Usage

```
Output of kokoro-clip --help command here.
```

## Examples

```
kokoro-clip
```
